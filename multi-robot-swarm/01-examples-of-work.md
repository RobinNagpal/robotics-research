# Examples of Work

## Deployed multi-robot fleets

- **Amazon Robotics** — 750k+ robots in warehouses, coordinated by a
  central WES.
- **Symbotic, Geek+, GreyOrange, Locus Robotics** — warehouse fleets,
  100-1000+ robots/site.
- **Ocado SH** — grid-based swarm in fulfillment centers.
- **Waymo / Cruise / Zoox** — multi-vehicle ride-hailing fleets.
- **Skydio Dock** — multi-drone autonomous operations.
- **Shield AI Hivemind / V-BAT swarms** — military drone teaming.
- **Anduril Lattice + Bolt / Ghost / Roadrunner** — multi-domain
  unmanned platforms.
- **Verity** — coordinated indoor drone inventory swarms.
- **Saildrone, Saronic** — multi-USV maritime patrols.

## Landmark research

- **Multi-Agent Path Finding (MAPF):** CBS, ECBS, EECBS, PBS, LaCAM.
- **Conflict-Based Search** (Sharon et al.).
- **MAPF-LNS, MAPF-RL** — learned-and-search hybrids.
- **MARL:** QMIX, MAPPO, IPPO, MADDPG.
- **DGN, MAGE-X** — graph-NN based MARL.
- **Hivemind / Counter-UAS swarm research** — DARPA OFFSET, AlphaPilot.
- **OneFlight / Swarm Drone Racing** (Penn / UZH).

## Open-source

ROS2 + multi-master / DDS discovery, Open-RMF (Open Robotics fleet
management), Nav2 fleet patterns, Crazyswarm 2 (Bitcraze + CMU),
LibMAPF, MAPF benchmarks.
