# Important Things to Learn

## Theory

- Graph theory, network flow, combinatorial optimization.
- Multi-agent path finding (MAPF): CBS, ECBS, EECBS, PBS, LaCAM.
- Task allocation: market-based (auctions), Hungarian assignment,
  Consensus-Based Bundle Algorithm (CBBA).
- Distributed consensus: Paxos, Raft basics; gossip protocols.
- Game theory / mechanism design for non-cooperative cases.
- Information-theoretic exploration (mutual-information formulations).

## MARL (multi-agent reinforcement learning)

- Independent learners (IQL, IPPO).
- Centralized training, decentralized execution (CTDE): MAPPO, QMIX,
  MADDPG.
- Graph-based MARL (DGN, GAT-based critics).
- Communication learning (DIAL, RIAL, CommNet).

## Systems and communications

- DDS / ROS2 multi-machine networking.
- Time synchronization (PTP, NTP, GPS-disciplined).
- Mesh / radio basics (LoRa, 5G, mesh Wi-Fi, military waveforms).
- Fleet observability: Foxglove, Prometheus, OpenTelemetry.

## Fleet management

- Job scheduling, dispatch optimization, queueing theory.
- Charging / battery-swap planning.
- Traffic management in shared aisles (zones, traffic lights, MAPF).
- Open-RMF concepts.

## Tools

Open-RMF, Crazyswarm 2, libMultiRobotPlanning, MAPF benchmarks,
Gazebo + multi-robot launch, ROS2 DDS tuning, PettingZoo (MARL), Isaac
Lab multi-agent envs.

## Must-read papers

CBS (Sharon et al.), EECBS, LaCAM*, "QMIX", "MAPPO", "Hivemind"
overviews, Open-RMF docs, Amazon Robotics talks on fleet WES.
