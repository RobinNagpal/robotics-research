# Examples of Work

## Deployed products

- **Waymo / Zoox / Cruise** — multi-camera + LiDAR perception stacks for
  full self-driving.
- **Tesla FSD** — camera-only "occupancy networks" + lane / object
  perception.
- **Mobileye EyeQ** — ADAS perception shipped in 100M+ vehicles.
- **Skydio drones** — fully autonomous obstacle-avoidance flight from
  6 cameras and on-board NN inference.
- **Boston Dynamics Spot / Atlas** — depth-camera-driven obstacle maps,
  semantic terrain.
- **Apple Vision Pro / iPhone LiDAR + ARKit** — real-time scene mesh,
  plane detection, hand tracking.
- **Pickle Robot / Symbotic / Covariant (acquired by Amazon 2024)** —
  warehouse pick perception (6-DoF pose, bin segmentation).
- **Veo / Verkada / Ambient.ai** — security-camera anomaly + person/event
  perception.

## Recent landmark research

- **NeRF** (2020) — neural radiance fields, started the neural-3D wave.
- **3D Gaussian Splatting** (Inria, 2023) — real-time photoreal 3D from
  photos; now mainstream in robotics digital twins.
- **Segment Anything (SAM 1/2)** (Meta, 2023-24) — promptable, universal
  segmentation; killed many bespoke segmenters overnight.
- **DINOv2** (Meta, 2023) — self-supervised vision features that work
  zero-shot for classification, retrieval, depth.
- **Depth-Anything v2** (2024) — monocular metric depth at production
  quality.
- **FoundationPose / MegaPose** (NVIDIA, 2024) — 6-DoF object pose from a
  single CAD model, no per-object training.
- **VGGT** (2025) — feed-forward 3D scene reconstruction from a few images.
- **CoTracker / TAPIR** — dense long-term point tracking through video.
