# SLAM & Navigation

Simultaneous Localization and Mapping (SLAM) and autonomous navigation —
how a robot knows where it is and how to get somewhere safely.

Spans visual-inertial SLAM, LiDAR SLAM, place recognition, global path
planning (A*, RRT*, lattice planners), and local planning / obstacle
avoidance.

A mature field that is being re-energized by learned components
(DROID-SLAM, NeRF-SLAM, end-to-end navigation policies).
