# Examples of Work

## Deployed systems

- **Waymo / Cruise / Zoox** — HD-map + LiDAR localization at
  centimeter accuracy.
- **iRobot Roomba j-series / Matic** — visual SLAM for home cleaning.
- **Skydio drones** — visual-inertial SLAM with on-board NN obstacle
  reasoning.
- **Boston Dynamics Spot Autowalk** — graph-based SLAM with fiducials.
- **Amazon warehouses (Symbotic, Proteus, Sequoia)** — fleet of AMRs
  with shared map + localization.
- **Locus Robotics / 6 River Systems / Geek+** — warehouse goods-to-person
  fleets.
- **Magic Leap / Apple Vision Pro / Meta Quest** — VIO + relocalization
  on-device.
- **DJI Mavic 3 / Avata** — vision-based positioning when GPS denied.

## Landmark research

- **ORB-SLAM / ORB-SLAM3** (Mur-Artal, Tardos) — gold-standard sparse
  visual SLAM.
- **LSD-SLAM, DSO** — direct (photometric) visual SLAM.
- **VINS-Mono / VINS-Fusion** (HKUST) — visual-inertial SLAM standard.
- **LIO-SAM, FAST-LIO, GLIM** — LiDAR-inertial SLAM.
- **DROID-SLAM** (2021) — first learned end-to-end SLAM at
  state-of-the-art accuracy.
- **NeRF-SLAM, Gaussian-SLAM, SplaTAM** (2023-24) — neural-3D SLAM.
- **ViNT / NoMaD** (Berkeley, 2023-24) — foundation model for visual
  navigation.

## Open-source pillars

ORB-SLAM3, OpenVSLAM, VINS-Fusion, Cartographer, RTAB-Map, FAST-LIO2,
GLIM, Nav2 (ROS2), MoveIt 2, OMPL.
