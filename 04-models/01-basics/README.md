# 01 — Basics: what a "model" is, before we name any

> **Read this first.** Every other folder in
> [`../`](../README.md) assumes you know what a *model* is, what
> *training* and *inference* mean, and roughly what hardware runs them.
> This folder builds that foundation from zero, for a reader who writes
> software but has never trained a neural network. Nothing here is
> robot-specific yet — it is the vocabulary you need before the
> robot-specific folders make sense.

## The documents in this folder
