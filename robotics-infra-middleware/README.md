# Robotics Infrastructure & Middleware

The plumbing layer of every robotics company: ROS2 / DDS, observability,
data pipelines, log replay, CI for robots, OTA updates, fleet
deployment.

Often overlooked but extremely well-paid because every robotics company
needs it and few people specialize in it. Pure software with no
hardware required to deliver value.
