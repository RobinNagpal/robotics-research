# Examples of Work

## Production simulators

- **NVIDIA Isaac Sim / Isaac Lab** — Omniverse-based, USD-native, GPU
  parallel envs; the de-facto industry sim.
- **NVIDIA Cosmos** (2025) — world-model platform for synthetic robotics
  data.
- **MuJoCo / MJX** (DeepMind) — fast, accurate contact physics; MJX is
  GPU-vectorized.
- **Genesis** (2024, CMU+) — open universal physics platform.
- **Gazebo / Ignition** — long-running ROS standard.
- **Drake** — model-based, contact-rich, used by Toyota Research.
- **CARLA, LGSVL/SVL, NVIDIA DRIVE Sim** — autonomous-vehicle sims.
- **AirSim, Microsoft AirSim, Flightmare** — drone sims.
- **Habitat 3.0** (Meta) — embodied AI / social nav.
- **AI2-THOR, iGibson, RoboCasa** — indoor manipulation sims.

## Digital-twin platforms

- **NVIDIA Omniverse + USD** — collaborative 3D + simulation.
- **Siemens Process Simulate, ABB RobotStudio, FANUC ROBOGUIDE** —
  industrial robot offline programming and twin.
- **Microsoft Azure Digital Twins** — generic IoT/factory twin.
- **Unity Industrial Collection, Unreal Twinmotion** — engine-based
  twins.
- **Cesium / Google 3D Tiles** — large-scale geospatial twins.
- **Matterport, Polycam, Luma AI** — 3D scan -> twin pipelines.

## Landmark research

- **Domain randomization** (Tobin et al., 2017).
- **OpenAI Rubik's cube** (2019) — dexterous sim-to-real.
- **ANYmal sim-to-real RL** (Hwangbo et al., 2019).
- **MimicGen** (NVIDIA, 2023) — synthetic demonstration generation.
- **DextrAH** (2024) — large-scale sim-to-real for dexterous hands.
- **3D Gaussian Splatting** + Sim2Real bridge work (2024-25).
- **RoboCasa** (NVIDIA, 2024) — large-scale kitchen sim.
- **Cosmos foundation world models** (NVIDIA, 2025).
