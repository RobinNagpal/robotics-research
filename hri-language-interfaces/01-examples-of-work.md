# Examples of Work

## Products in the field

- **Diligent Robotics Moxi** — hospital service robot with social
  signaling (head/eye gestures) for hallway interactions.
- **Bear Robotics Servi / Pudu BellaBot** — restaurant servers with
  voice + tablet interface.
- **Amazon Astro** — home robot with conversational frontend.
- **Figure 02 + Helix** — voice-commanded humanoid demos.
- **1X NEO** — voice-instructed household tasks.
- **Robust.AI Carter** — collaborative warehouse cart with HRI focus.
- **Boston Dynamics Spot + Spot SDK ChatGPT integration** — voice tour
  guide demos.
- **Apptronik Apollo** — natural-language task instruction at the demo
  level.

## Landmark research

- **SayCan** (Google, 2022) — LLM proposes actions, robot affordances
  filter them.
- **Code-as-Policies** (2022) — LLM emits Python that calls robot APIs.
- **Inner Monologue, ProgPrompt** (2022-23) — LLMs as planners with
  feedback.
- **VoxPoser** (Stanford, 2023) — LLM + VLM compose 3D value maps.
- **TidyBot** (2023) — personalized household tidying via LLM
  preferences.
- **RT-2 / Gemini Robotics** — VLAs that take language directly.
- **HumanPlus / OKAMI** — humanoid imitation from human video.
- **Social-LSTM, Trajectron++** — pedestrian-aware navigation.

## Open-source / off-the-shelf building blocks

OpenAI Whisper / Distil-Whisper (ASR), Piper / Coqui / ElevenLabs (TTS),
Llama / Qwen / Gemma (on-device LLMs), MediaPipe (pose, hand, face),
ROS2 + LangChain bridges (rosa, llm_robot).
