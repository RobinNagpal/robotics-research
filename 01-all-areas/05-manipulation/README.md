# Manipulation & Grasping

Grasping, dexterous manipulation, bin picking, assembly, and bimanual
tasks — the canonical "hard problem" of robotics.

Long-tail of object diversity, contact-rich physics, and tight latency
make it the field where VLAs, diffusion policies, and tactile sensing
are converging fastest.
