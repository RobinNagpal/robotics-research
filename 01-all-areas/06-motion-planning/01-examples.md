# Examples of Work

## Production-grade systems

- **Boston Dynamics Atlas / Spot** — model-predictive control + whole-
  body optimization; canonical reference for legged MPC.
- **Agility Digit** — humanoid logistics, MPC + learned policies.
- **ANYbotics ANYmal** — RL-trained locomotion deployed in industry.
- **Apptronik Apollo, Figure 02, 1X NEO** — whole-body controllers with
  RL + MPC hybrids.
- **SpaceX Starship landing burn** — convex MPC at production scale.
- **Boston Dynamics Stretch** — case-by-case planned manipulation.
- **MoveIt 2 + OMPL** — open-source motion planning stack used by
  thousands of arms.

## Landmark research

- **Differential Dynamic Programming (DDP) / iLQR** — basis of modern
  trajectory optimization.
- **DRAKE** (MIT, Tedrake) — toolbox for model-based robotics.
- **CHOMP, STOMP, TrajOpt, GPMP2** — classic trajectory optimizers.
- **Convex MPC for legged robots** (Di Carlo et al., MIT Cheetah).
- **ANYmal RL locomotion** (Hwangbo et al., Hutter group, 2019) — proved
  sim-to-real RL works on legged robots.
- **Walk these Ways** (Margolis, Berkeley, 2022) — adaptive locomotion
  policies.
- **Diffusion Policy** — replaces MPC for manipulation in many cases.
- **TD-MPC2, DreamerV3** — world-model based control.
- **DeepMimic, ASE, AMP** — physics-based character / humanoid control.

## Open-source tools

DRAKE, MoveIt 2, OMPL, OCS2, Crocoddyl, Pinocchio, RaiSim, MuJoCo
MPC, ACADOS, CasADi.
