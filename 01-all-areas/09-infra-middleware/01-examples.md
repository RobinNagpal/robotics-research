# Examples of Work

## Production-grade middleware

- **ROS / ROS2** — the lingua franca; ROS2 Humble / Iron / Jazzy.
- **DDS implementations:** Cyclone DDS, Fast DDS, RTI Connext.
- **Apex.OS / Apex.AI** — automotive-grade certified ROS2 fork.
- **Zenoh** (Eclipse) — emerging pub/sub/query protocol; gaining
  traction in robotics.
- **Yocto / Buildroot / NVIDIA L4T** — embedded Linux distros for
  robots.
- **NVIDIA Isaac ROS** — accelerated ROS2 nodes on Jetson.
- **micro-ROS** — for MCUs.

## Observability and replay

- **Foxglove Studio + Foxglove Data Platform** — Datadog for robots;
  big fundraising in 2023-24.
- **Rerun.io** — multimodal time-series logging for robots and ML.
- **rosbag2, MCAP** — canonical recording formats.
- **PlotJuggler, RViz2** — open-source debugging.

## Fleet ops platforms

- **Formant, InOrbit, Freedom Robotics, Cogniteam, Polymath** — robot
  ops SaaS.
- **AWS RoboMaker** (and successors) — cloud robotics infra.
- **Microsoft Azure Percept / IoT for robotics** — fleet management.
- **Husarnet, Husarion, Wandelbots** — niche orchestrators.

## Robotics CI / data infra

- **Rerun.io, MCAP, Foxglove** — data plumbing.
- **Cortex (defunct, but recent companies follow this pattern)** — CI
  for robot software.
- **Apple's internal AppleAVF / Waymo's internal tooling** — closed but
  shape the field.
- **DataBricks, Modal, Anyscale Ray** used by robot data teams.

## Landmark efforts

- **ROS Enhancement Proposals (REPs)** — design docs that define the
  ecosystem.
- **MCAP file format** (Foxglove, 2022) — modern replacement for rosbag.
- **Zenoh-ROS2 bridge** — wide-area fleet messaging.
- **isaac_ros NITROS** — type-adapted zero-copy graphs on Jetson.
