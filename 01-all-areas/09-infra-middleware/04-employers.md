# Major and New Employers

## Established

- **Open Robotics / Intrinsic (Alphabet)** — ROS2 stewards.
- **NVIDIA Isaac ROS team** — accelerated ROS2 on Jetson.
- **Apex.AI** — automotive-grade ROS2, autoware ecosystem.
- **Bosch Open Source / Bosch Research** — large ROS2 contributor.
- **Microsoft Azure / AWS Robotics teams** — cloud robotics infra.
- **Boston Dynamics platform team** — internal middleware.
- **Waymo / Cruise / Zoox infra teams** — large internal middleware
  groups; some of the best-paid infra ICs in robotics.
- **Anduril Lattice** — large platform team.

## Companies founded 2018-2025 (or scaled then)

- **Foxglove** (2021) — robotics observability; raised Series-A 2023.
- **Rerun.io** (2022) — multimodal logging for robotics + ML; OSS-first.
- **Formant** (2017, scaled past 2022) — fleet ops SaaS.
- **InOrbit** (2018, scaled past 2022) — fleet ops, RobOps community.
- **Freedom Robotics** (2018, scaled past 2022) — fleet ops.
- **Cogniteam** (Israel) — orchestration platform.
- **Polymath Robotics** (2022) — drive-by-wire autonomy for industrial
  vehicles.
- **Tangram Vision** (2020) — sensor calibration + perception
  middleware.
- **ZettaScale** (Zenoh maintainers, founded 2018, scaling 2023+) —
  next-gen pub/sub.
- **Husarnet** (2018) — robotics VPN/networking.
- **Polymath, Standard Bots, Formic** — robot-as-a-service infra.
- **MIRMI / Intrinsic Flowstate** — visual programming + middleware.
- **Cobot** (2022) — internal stack worth studying.

## Where infra engineers earn the most

Waymo, Cruise, Zoox, NVIDIA Isaac ROS, Apex.AI, Anduril, Shield AI,
Apple, Boston Dynamics. Infra and platform ICs at top robotics
companies often clear $250-400k TC because the supply of engineers who
truly understand ROS2 + DDS + real-time + Linux + cloud is tiny.

Salary Guide 2025 notes the "Embedded Systems / Real-Time / Linux"
combination is in particular demand and undersupplied.
