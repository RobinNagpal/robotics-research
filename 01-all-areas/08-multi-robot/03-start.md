# How to Get Started

## Week 1-2: MAPF foundations

- Read the CBS / ECBS / LaCAM papers.
- Implement A* for grid worlds, then CBS for 2-agent and 5-agent grid
  MAPF in Python.
- Run the open MAPF benchmarks.

## Week 3-4: Fleet management

- Walk through Open-RMF tutorials: book a delivery task across a fleet
  in simulation.
- Stand up 4-8 TurtleBot3 sims in Gazebo and route them with Open-RMF
  + Nav2.

## Week 5-6: MARL

- Set up PettingZoo or VMAS (Vectorized Multi-Agent Simulator).
- Train QMIX or MAPPO on a cooperative navigation task.
- Try a small swarm in Isaac Lab with parallel envs.

## Week 7: Drones

- Run Crazyswarm 2 in sim with 5-20 virtual Crazyflies.
- Implement a leader-follower formation or a Boids-style flocking
  controller.

## Week 8: An end-to-end showcase

Pick one:

- A small warehouse sim with 10 AMRs running CBS-based MAPF and a job
  dispatcher.
- A drone swarm doing search/coverage of a polygon, simulated in Gazebo.
- A multi-arm cell where two arms must coordinate to assemble an object.
